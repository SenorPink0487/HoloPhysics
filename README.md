# 未来物理实验室 · HoloPhysics (Quantum Physics Lab)

基于 **Tauri 2 + Vite + Three.js** 构建的交互式 3D 虚拟物理实验室与 AR 空间手势实验终端。

本系统深度集成 **MediaPipe Hands** 神经网络模型，支持通过常规笔记本/台式机普通摄像头，实现纯粹依靠双手手势（无接触式）对物理实验参数的调节、视角自由回转和空间漫游。

## 🌟 核心功能特性

1. **三维交互式物理实验室**：
   - **力学桌**：单摆简谐运动与阻尼分析、弹簧挂重受力与共振实验。
   - **光学桌**：精密双缝干涉条纹计算、几何光学棱镜折射与透镜光路成像。
   - **电磁学桌**：静电场与高斯定理、法拉第电磁感应、感生电场涡旋可视化、霍尔效应原理与霍尔效应测磁。
   - **热力学桌**：固体热传导傅里叶定律模拟。
2. **MediaPipe 隔空空间手势追踪 (AR Mode)**：
   - **单手捏合旋转**：食指与大拇指捏合后平滑移动，可隔空自由回转观测视角。
   - **双手协同漫游 (Locomotion)**：双手同时捏合并进行拉伸或推拢操作，实现前后漫游前进或倒退。
   - **精准光线指针**：手部准星实时投射射线，通过算法优选自动捕捉前置交互部件，并支持捏合无级拖动调节摆长、质量或波长。
3. **量子水晶玻璃 HUD 导引终端**：
   - 界面左上角配备使用教程终端，基于**轻柔水晶玻璃拟物美学（Crystal Light Glassmorphism）**与全套矢量 SVG 图标设计，直观呈现双输入模态的物理操作指南。
4. **多端自适应与性能冗余**：
   - 支持纯 Web 浏览器热更新开发，也支持打包为 Tauri 桌面级轻量原生应用。
   - 内置神经网络低光照自动丢帧保护与稳态平滑滤波（One Euro Filter / 三值中值滤波）。

## 🛠️ 技术栈与依赖

- **Tauri 2** — Rust 原生桌面容器壳，安全沙盒与打包。
- **Vite 6** — 极速前端构建工具。
- **Three.js** (WebGL) — 实时 3D 物理实验室渲染引擎。
- **MediaPipe Hands** — 端侧实时手势检测与 21 节点关节重构。
- **One Euro Filter** — 对动态手势关节进行防抖与超低延迟平滑滤波。
- **GSAP** — 启动全息加载动画。
- **ldrs** — Quantum 量子风格加载指示器。

## 📦 安装与运行

### 环境要求
- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/)（推荐 `rustup`）
- **Windows** 开发依赖：
  - [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)（含 MSVC 编译器）
  - WebView2 Runtime（Windows 10/11 系统通常已内置）

### 常用运行命令
```bash
# 1. 安装核心依赖
npm install

# 2. 纯 Web 开发调试（浏览器中打开）
npm run dev

# 3. 运行 Tauri 桌面应用窗口（自动加载前端热更新）
npm run dev:tauri

# 4. 构建前端静态资源（输出至 dist/）
npm run build

# 5. 打包为桌面级安装包 (Windows .msi 或可执行二进制文件)
npm run build:tauri

# 6. 运行自动化单元测试
npm test
```

## 🕹️ 交互控制指南

### 1. 常规键鼠神经终端
| 输入 | 交互效果 |
| :--- | :--- |
| **`W` `A` `S` `D`** | 实验室空间前后左右平滑移动 |
| **`Space` / `Shift`** | 视角高度垂直上升 / 垂直下潜 |
| **点击屏幕** | 锁定视角进入精密准心定位模式 |
| **`E` 或 点击左键** | 触发所瞄准仪器的电路、开关或全息屏 |
| **按住左键并左右拖曳**| 连续调节单摆摆长、弹簧质量、激光波长与磁轨定位 |
| **`F` 键** | 精准捕捉并记录当前实验测量数据点 |
| **`H` 键** | 唤起/隐藏相机 AR 空间手势追踪 |
| **`Esc` 键** | 解锁鼠标指针，或退出当前正在查看的子窗口 |

### 2. AR 隔空全息追踪引擎
| 输入 | 交互效果 |
| :--- | :--- |
| **单手捏合 + 轻移手腕** | 在无仪器空处做出捏合姿势，可隔空自由回转视角 |
| **双手捏合 + 展开/收拢** | 双手同时做出捏合姿势，张开向前漫游，收拢向后倒退 |
| **瞄准仪器 + 单手捏合拖曳**| 准心对准滑轨时，捏合手势并左右划过即可隔空精密调节参数 |
| **智能状态保护** | 当光线过暗神经网络丢帧时，系统将无感降级并保持最后稳定姿态 |

## 📈 开发与调试提示

- **混合运行架构**：`src/tauri.js` 能够智能感知当前是在 Tauri 宿主还是普通 Web 浏览器中。在浏览器中会自动屏蔽 Rust IPC 命令并以模拟数据进行安全降级。
- **Web Worker 加速**：手部 21 关节特征检测运行在 Web Worker 线程中，确保在运行高密度 3D 物理公式模拟时仍能保持渲染帧率的稳定。
- **单元测试**：使用 `npm test` 即可跑通包含手姿态检测、One Euro 滤波器拟合、物理偏转临界值检测等 44 项全覆盖测试，以保障物理计算的严谨性。
